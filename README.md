# PIC-Greenhouse-Monitoring-and-Control-System
Proteus 8 Professional design files for a PIC-based Greenhouse Monitoring and Control system that simulates real-time sensing of temperature and soil moisture, and automatically controls actuators such as fans, heaters, and irrigation to maintain optimal plant-growing conditions.

Design Tools

EDA Software: Proteus 8 

Microcontroller: PIC16F877

Programming Environment: mikroC PRO for PIC
